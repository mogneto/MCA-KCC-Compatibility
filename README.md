# MCA KCC Compatibility

NeoForge compatibility mod that connects **Minecraft Comes Alive (MCA)** with **Kingdom Come Combat (KCC)** in Minecraft 1.21.1.

## Features

- Gives armed MCA male and female villagers a configurable KCC humanoid combat profile.
- Uses MCA's brain memories for target selection.
- Applies KCC combat poses to villager models.
- Integrates MCA's extended player model with the Player Animation Library.
- Keeps MCA and KCC as optional mod dependencies.

## Requirements

- Minecraft 1.21.1
- NeoForge 21.1+
- Minecraft Comes Alive
- Kingdom Come Combat

## Building

Java 21 is required.

```powershell
.\gradlew.bat build
```

The packaged mod is generated in `build/libs`.

## Development

```powershell
.\gradlew.bat runClient
.\gradlew.bat runServer
```
